# Phantom — Real-Time AI Interview Copilot for macOS & Windows

Phantom is a native desktop overlay designed to assist software engineers and technical candidates during live interviews, system design rounds, and coding challenges.

[![Website](https://img.shields.io/badge/Website-phantominterview.in-blue)](https://phantominterview.in)
[![Platform](https://img.shields.io/badge/Platform-macOS%20%7C%20Windows-lightgrey)](#platform-support)

---

## Key Features

- **Native Desktop Overlay:** Lightweight, low-latency UI optimized for Apple Silicon (macOS) and Windows.
- **Resume & Context Integration:** Tailors real-time suggestions using your uploaded resume and project experience.
- **Zero Audio Capture:** Does not join meetings as a bot or capture third-party meeting audio.
- **Screen-Share Invisibility:** Designed to run silently without interfering with standard screen sharing.
